# jikgwan-fairy-data

토스 미니앱 "직관 승리요정"이 읽는 프로농구 · 프로배구 경기 결과와 순위 파일입니다.

- `data/schedule.json` : 시즌 일정과 결과 `[날짜, 시작 시간, 홈, 원정, 홈 점수, 원정 점수]` (아직 안 한 경기는 점수 null, 배구는 세트 수)
- `data/standings.json` : 팀 시즌 승패

## 어떻게 모으나

- 출처는 각 리그 공식 누리집(KBL · WKBL · KOVO) 일정 · 순위 페이지입니다.
- 경기가 끝났을 시간(시작 + 농구 2시간 · 배구 2시간 30분)이 지났는데 결과가 비어 있을 때만 그 리그 페이지를 엽니다. 그 밖에는 접속하지 않습니다. 하루 한 번 새벽에 시즌 전체 일정과 순위를 다시 읽습니다.
- 결과로 계산한 승패가 공식 순위와 다르면 경고를 남기고, 끝난 경기 수가 줄어드는 등 이상하면 파일을 바꾸지 않습니다.

경기 기록의 권리는 각 리그에 있습니다. 문제가 있으면 이 저장소 이슈로 알려 주시면 바로 중단합니다.
